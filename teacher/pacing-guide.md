<div class="section-header">
  <span class="section-number">Teacher Resource</span>
  <h1>Pacing Guide</h1>
</div>

<p>Suggested timing for 80-minute block periods, every other day. Adjust based on your students' pace — the site is self-paced, so faster students can move ahead while you support those who need more time.</p>

<div class="callout callout-info">
  <span class="callout-title">Block Schedule Assumption</span>
  <p>80-minute periods, every other day. Total lesson time: approximately 5–7 block periods depending on student pace and print queue logistics.</p>
</div>

<div class="callout callout-key">

  <p>Assign the CNC Kitchen video before Period 1. This saves 10–15 minutes and lets students arrive with visual context for the material properties discussion.</p>
</div>

<div class="table-wrap">
<table>
  <thead>
    <tr><th>Time</th><th>Activity</th><th>Section</th></tr>
  </thead>
  <tbody>

    <tr><td>0:30–0:55</td><td>Section 5: Print the Specimen — configure Bambu Studio, verify settings, start prints</td><td>5</td></tr>
    <tr><td>0:55–1:20</td><td>Continue printing / Students document settings + label specimens</td><td>5</td></tr>
  </tbody>
</table>
</div>

<div class="callout callout-info">
  <span class="callout-title">Print Queue Strategy</span>
  <p>With a Bambu Lab P1S, each test bar (~80×10×4mm at 100% infill) takes approximately 25–35 minutes. Plan for:</p>
  <ul>
    <li><strong>3 specimens per student/team × ~30 min each = ~90 min per student</strong></li>
    <li>Run print batches during class time + overnight if possible</li>
    <li>Have students prepare their Bambu Studio files in Period 3, queue prints in order</li>
    <li>Some prints will carry into Period 4 — that's normal</li>
  </ul>
</div>

<h2>Period 4 — Break It</h2>

<div class="table-wrap">
<table>
  <thead>
    <tr><th>Time</th><th>Activity</th><th>Section</th></tr>
  </thead>
  <tbody>
    <tr><td>0:00–0:10</td><td>Distribute specimens (24hr conditioning should be complete). Review test procedure.</td><td>6</td></tr>
    <tr><td>0:10–0:55</td><td>Section 6: Physical testing — three-point bend, data collection</td><td>6</td></tr>
    <tr><td>0:55–1:10</td><td>Calculate flexural stress and modulus from data</td><td>6</td></tr>
    <tr><td>1:10–1:20</td><td>Photo documentation of broken specimens</td><td>6</td></tr>
  </tbody>
</table>
</div>

<div class="callout callout-warn">
  <span class="callout-title">Safety</span>
  <p>When PLA specimens fail in bending, fragments can fly. Require safety glasses during testing. Specimens under load can snap suddenly — keep fingers away from the loading point. Demonstrate proper hand placement before students begin.</p>
</div>

<h2>Period 6–7 — The ABS Trap (Advanced, if time allows)</h2>

<div class="table-wrap">
<table>
  <thead>
    <tr><th>Time</th><th>Activity</th><th>Section</th></tr>
  </thead>
  <tbody>
    <tr><td>Period 6: 0:00–0:30</td><td>Section 8: Run simulation with default ABS, record predictions</td><td>8</td></tr>
    <tr><td>Period 6: 0:30–1:20</td><td>Print ABS specimens (may need to extend into off-class time)</td><td>8</td></tr>
    <tr><td>Period 7: 0:00–0:40</td><td>Break ABS specimens, collect data</td><td>8</td></tr>
    <tr><td>Period 7: 0:40–1:00</td><td>Create corrected ABS profile, re-run simulation</td><td>8</td></tr>
    <tr><td>Period 7: 1:00–1:20</td><td>Side-by-side comparison table + final reflection</td><td>8</td></tr>
  </tbody>
</table>
</div>

<div class="callout callout-key">
  <span class="callout-title">Section 8 Is Optional But Powerful</span>
  <p>If you only have 5 periods, stop after Section 7. The core lesson is complete. But if you have 7 periods, Section 8 is where the deepest learning happens — students experience firsthand what happens when material assumptions are wrong.</p>
</div>
