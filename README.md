# FEA SolidWorks 2025

Predict. Print. Break. Compare.

A self-paced GitHub Pages lesson for high school CTE engineering students. Run a SolidWorks FEA simulation, 3D print the part, physically break it, and compare prediction to reality.

**School:** Crescent Valley High School, Corvallis, Oregon
**Students:** High school juniors, CSWA-level SolidWorks
**Teacher:** Adam Kirsch
**Software:** SolidWorks 2025
**Printer:** Bambu Lab P1S

## Lesson Flow

| Phase | Sections | What Students Do |
|-------|----------|-----------------|
| Learn | 1–2 | Physics vocabulary, FEA workflow |
| Simulate | 3–4 | Set up and run a static study, read stress plots |
| Build & Test | 5–6 | 3D print specimens, three-point bend test |
| Analyze | 7 | Calculate percent error, write reflection |
| Advanced | 8 | ABS Trap — wrong material investigation |

## Deploy

1. Fork or clone this repository
2. Settings → Pages → Source: main branch
3. Site deploys to `https://[username].github.io/fea-solidworks-2025/`

## Self-Paced Design

Every section includes a "Working on your own?" note that scaffolds prerequisites, required materials, and context for students working independently. An advanced student who misses a lecture can navigate the full lesson without additional instruction.

## Local Development
